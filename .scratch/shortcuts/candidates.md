# Shortcut candidates

Every candidate Shortcut found in the MPC Sample User Guide v1.0, plus the five you listed. Delete the lines you don't want and fix any wording; this file becomes the source for the Shortcuts Tool.

Page numbers are only here to help you verify; the app won't show them.

**Flags**

- ✅ you've verified it on the device
- `[printed: X]` a special use of something printed on the panel (X)
- `[on-screen]` a SHIFT function shown only by the small ⬆ icon on the display
- `[normal]` arguably just how the Control normally works
- `[unsure]` the manual is ambiguous

## Any Mode

- [x] ✅ Press STOP (■) twice → Stop all audio
- [x] ✅ Hold SHIFT + press PAD BANK → Select the previous pad bank
- [x] ✅ Hold TAP TEMPO + turn ENCODER → Change the tempo
- [x] ✅ Hold TAP TEMPO + press and turn ENCODER → Change the tempo's decimals
- [x] Hold PAD BANK + press pad 1–8 → Jump straight to pad bank A–H (p19)
- [ ] Hold NOTE REPEAT → Note Repeat only while held (p19)
- [x] Hold ERASE + hold a pad during playback → Erase that pad's events as they play (p18, 41)
- [x] Hold ERASE + turn K1–K3 or move the fader → Erase that automation; B3 confirms, B1 cancels (p19, 41)
- [ ] Hold SHIFT while Note Repeat is on → Show triplet divisions on B1–B3 (p19) `[printed: TRIPLET]`
- [x] Hold SHIFT + ERASE, press destination pads, release → Copy to those pads (p19) `[printed: COPY]`

## Sample Mode

- [x] ✅ Hold SAMPLE + press a pad → Select the pad without playing it
- [x] Hold ERASE + press a pad while stopped → Delete the pad's sample (p18)
- [ ] Hold MUTE → Mute pads only while held (p22, 34)
- [x] Press ENCODER → Move between the K1–K3 parameters (p24) `[normal]`
- [x] Hold SHIFT + press ENCODER → Move between the K1–K3 parameters backwards (p24)
- [ ] SHIFT + K1 / K2 / K3 → Zoom in at Start / End / Loop (Trim page) (p25) `[on-screen]`
- [ ] SHIFT + B1 → Toggle Loop Lock (p25, 33) `[on-screen]`
- [ ] SHIFT + K2 → Kit volume (Mix page) (p25) `[on-screen]`
- [ ] SHIFT + K2 → Pad Link (p28) `[on-screen]`

## Sequence Mode

- [x] Hold SHIFT + turn ENCODER → Move the playhead by the Q value instead of by beats (p39)
- [x] Hold SEQ + press SAMPLE (or the other way round) → Sample/Seq Mode: keep the sequence display while the pads play samples (p40)
- [ ] Hold B1 + turn ENCODER (press ENCODER to switch to decimals) → Set the sequence tempo (p39) `[unsure]`
- [ ] Hold ERASE + press a pad → Erase that sequence (p18)
- [x] SHIFT + K1 → Sequence length, 1–128 bars (p39) `[on-screen]`
- [x] SHIFT + K2 → Time signature (p39) `[on-screen]`
- [ ] SHIFT + K3 → Metronome volume (p40) `[on-screen]`
- [ ] Press SAMPLE while recording is armed → Go back to the pads and stay armed (p41)
- [x] Press SEQ RECORD again while recording → Stop recording but keep playing (p41)
- [ ] SHIFT + − (UNDO) straight after recording → Undo everything from the last recording pass (p41) `[printed: UNDO]`

## Step Edit

- [x] Hold ERASE + press a pad → Erase all of that pad's events (p18, 43)
- [ ] Hold B1 + turn ENCODER (press ENCODER to switch to decimals) → Set the tempo (p43) `[unsure]`
- [ ] SHIFT + K2 → Time signature (p43) `[on-screen]`
- [x] Move the fader → Nudge the selected event's timing (p18) `[normal]`
