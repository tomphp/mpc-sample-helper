# Flutter for web now and mobile later

MPC Sample Helper is built as a Flutter app. It runs in the browser first (locally, later publicly hosted), and is intended to ship as a phone app later from the same codebase. A plain web app would be simpler for a small reference tool, but would need a rewrite or a wrapper to become a good native phone app; Flutter accepts some web-side weight in exchange for one codebase across both.
